# C 组分镜：预副歌二 + 副歌二「破」（帧 3534–4839，117.80–161.30s）

代码：units/sec_c_pre2_chorus2.py（镜头类）、units/c_kit.py（雷暴/字幕/相机）、units/c_props.py（第二棒新道具）。联系表：tools/c_contact.py。

## 总体设计
- 叙事位置：长夜→雨夜→**风暴之眼**。预副歌二 = 烛光暗房里的「剧本 / 提线 / 天平 / 暗箱」（权力在幕后定规则，暖金、宋体铅字打字机）；「我不低头」起切进雨夜，他的字体换成自己的重字（Black 飞入）。副歌二 = 雷暴：军阵、律令字墙、巨印、天平，被一刀刀斩开。
- 与副歌一（月夜·金裂砖墙）区分：本段**不出现月亮与金裂砖墙**；墙是宋体律令字砖墙（冷色、雷光），只在 C22–C27 一组里推进（远景→局部→横移→劈→崩→缺口），每镜景别/方向不同。
- 与基线扣分对照：不再用宣纸+红日模板（S061/S062/S065 套路）；无矢量大刀（刀全部是生图 blade_hot / blade_level 或人物手里的刀）；不出现剪影站山头；歌词不走底部字幕条，每段一套（预副歌铅字打字机+朱红光标+故障出场 / 副歌飞入+碎裂出场 / 画内字：刻在牌、砖、印、刀上）。
- 第二棒改动：道具全部换成 c_props 的材质化版本（墨玉巨印=透视立方体+石纹+朱砂阳文+金填阴刻、漆金暗箱、青铜天平=圆柱着色+铜绿+碗形秤盘、立体字砖、立体铅活字）；C03 改纯代码手影+十字提线板（S062 精灵降到 2 次）；C13 加风暴之眼漩涡+光速雨线+赤热核心；C28「亮」改墨边金芯可读；C36 加跪伏方阵（C18 冲锋方阵的回声）；C18 方阵改用 crowd.Army 直接合成并中线分开。

- C41 巨型秤盘放大后口沿偏薄，像一个环；C32 奔跑的小人偏小偏糊。
- C02 提线挂字画面偏空（字小、手被画顶裁）。
- 仅看了中点帧和部分镜头 3–4 帧抽样，未出动态预览，镜内运动与转场节奏未经视频验证。
